# 灵龙2.0 关键参数与动作 — 视觉参考手册

> **用途**:以后设计任何动作时,翻这一份就知道每个关节值对应什么视觉。
> **校准日期**:2026-08-09
> **校准依据**:`calibration/` 目录下 21 张测试 PNG(实测)
> **适用模型**:`model/LingLong2.0/LingLong2.0.urdf`

---

## 1. 模型基本信息

| 项 | 值 |
|---|---|
| 关节数 (`njnt`) | 30 |
| 自由度数 (`nq`) | 30(全部 1-DOF) |
| 执行器数 (`nu`) | 0(纯运动学) |
| **是否含 free joint** | **否** — **无 floating base** |
| 关节类型 | 全部 `mjJNT_HINGE`(type=3) |
| 渲染 | 默认纯灰(`sim/calibrate.py` 用的视角:3/4 右上,俯 15°) |

### 坐标系约定

- **画面里"右"** = **机器人的左手侧**(镜像)
- **画面里"左"** = **机器人的右手侧**
- "机器人视角" 的左/右跟人面对面观察的方向相反
- 关节限位的"+/-" 方向见 §3

### 最容易踩的坑

- **qpos0 不是"自然站立"**,而是"**大臂下垂 + 小臂前伸 90°**"的功能位姿
- **所有 `pitch` 类关节的 +方向都跟直觉相反**:`+` 是后/下,`-` 才是前/上
- **左/右肩 roll 限位完全镜像**:左 `[-0.09, +3.05]`,右 `[-3.05, +0.09]`,所以抬双臂时必须一个 + 一个 -
- **没有 free joint** → 不能做位移、跳、走,只能做原地动作

```
├─ left_leg(0-5)          ├─ 12 waist_yaw            ├─ left_arm(16-22)
│  ├─ 0  hip_pitch        ├─ 13 waist_pitch          │  ├─ 16 shoulder_pitch
│  ├─ 1  hip_roll         ├─ 14 head_yaw             │  ├─ 17 shoulder_roll
│  ├─ 2  hip_yaw          └─ 15 head_pitch           │  ├─ 18 shoulder_yaw
│  ├─ 3  knee                                        │  ├─ 19 elbow
│  ├─ 4  ankle_pitch                                 │  ├─ 20 wrist_roll
│  └─ 5  ankle_roll                                  │  ├─ 21 wrist_pitch
└─ right_leg(6-11)        命名规则:                  │  └─ 22 wrist_yaw
   (同上,镜像)              {左/右}_{部位}_{类型}_joint  └─ right_arm(23-29)
                                                       (同上,镜像)
```

## 3. 关键参数表(30 关节完整)

> 每行:**+方向视觉** = 设 +1.0 时看到什么;**-方向视觉** = 设 -1.0 时看到什么;**0 位视觉** = 设 0 时看到什么;**常用值** = 设计动作时的推荐范围。

### 3.1 头部(头不动则整段不动)

| 关节 | qpos | 限位 | +方向 | -方向 | 0 位 | 常用值(动作设计) |
|---|---:|---|---|---|---|---|
| `head_yaw_joint`     | 14 | [-1.57, +1.57] | 头向**机器人左手**转(画面右) | 头向**机器人右手**转(画面左) | 朝前 | 摇头 ±0.4~±0.8 |
| `head_pitch_joint`   | 15 | [-0.79, +0.79] | **低头**(非直觉) | **抬头**(非直觉) | 朝前 | 点头 ±0.2~±0.4 |

### 3.2 腰部(上身所有运动都从这俩起)

| 关节 | qpos | 限位 | +方向 | -方向 | 0 位 | 常用值 |
|---|---:|---|---|---|---|---|
| `waist_yaw_joint`    | 12 | [-2.62, +2.62] | 上身向**机器人左手**扭 | 上身向**机器人右手**扭 | 朝前 | 扭腰 ±0.3~±0.5 |
| `waist_pitch_joint`  | 13 | [-0.52, +0.52] | **弯腰(前倾)**(非直觉) | **后仰**(非直觉) | 直立 | 鞠躬 +0.4~+0.5 |

### 3.3 双臂(11 关节 ×2,22 个) — 设计动作最常用

#### 3.3.1 肩部(每臂 3 个,pitch 方向反直觉)

| 关节 | qpos | 限位 | +方向 | -方向 | 0 位 | 常用值 |
|---|---:|---|---|---|---|---|
| `left_shoulder_pitch_joint`  | 16 | [-2.97, +2.97] | 大臂**向后**摆(非直觉) | 大臂**向前**摆 | 大臂自然垂 | 前推 -0.5~-1.0,后摆 +0.5~+1.0 |
| `right_shoulder_pitch_joint` | 23 | [-2.97, +2.97] | (镜像)大臂**向后** | (镜像)大臂**向前** | 大臂自然垂 | (同上) |
| `left_shoulder_roll_joint`   | 17 | [-0.09, +3.05] | 大臂**抬高**(往侧上) | 大臂**贴身体** | 默认贴身体 | 侧平举 +1.57,举高 +2.5~+2.8,过头 ≈+2.8 |
| `right_shoulder_roll_joint`  | 24 | [-3.05, +0.09] | (镜像)大臂**贴身体** | (镜像)大臂**抬高** | 默认贴身体 | (镜像同上) |
| `left_shoulder_yaw_joint`    | 18 | [-2.97, +2.97] | (未实测)推测:大臂水平**向外** | **大臂向内收到中线**(实测:-0.997 让左臂收向胸前) | 默认 | 收向中(合十):-1.0 |
| `right_shoulder_yaw_joint`   | 25 | [-2.97, +2.97] | (镜像)**大臂向内收** | (镜像)大臂水平向外 | 默认 | 收向中(合十):+1.0 |

**双臂镜像口诀**:
- 抬双臂:左 roll=+大值,右 roll=**-**大值(roll 符号相反,绝对值相同)
- 伸双臂向前:左 pitch=负值,右 pitch=**-**负值(实际上**同号**即可,pitch 镜像是对称)
- 展双臂 T-pose:左 roll=+1.57,右 roll=-1.57 ✓(C1 已验证)

#### 3.3.2 肘部(每臂 1 个)

| 关节 | qpos | 限位 | +方向 | -方向 | 0 位 | 常用值 |
|---|---:|---|---|---|---|---|
| `left_elbow_joint`   | 19 | [-0.79, +1.57] | 小臂**伸直**(从 90° 前伸变直) | **小臂向上弯**(实测:-0.324 让左前臂收向胸前,做"合十"用) | **小臂前伸 90°**(非下垂!) | 合十:-0.3,T-pose/垂臂:+1.0,弯曲:负值 |
| `right_elbow_joint`  | 26 | [-0.79, +1.57] | (镜像)小臂**伸直** | (镜像)**小臂向上弯** | 小臂前伸 90° | (同上) |

**关键陷阱**:elbow=0 ≠ 小臂下垂,而是"小臂前伸 90°"。要"自然站姿双臂垂"必须 `elbow ≈ +1.0`(伸直下垂)。**elbow 负方向 = 小臂向上弯**,这是做"合十""抱胸""举物"等动作的关键。

| `left_wrist_pitch_joint` | 21 | [-1.40, +1.40] | 默认 | 暂未实测 |
| `left_wrist_yaw_joint`   | 22 | [-1.40, +1.40] | 默认 | 暂未实测 |
| `right_wrist_*` (3 个)   | 27-29 | 同左 | 默认 | 暂未实测 |

|---|---:|---|---|---|---|---|

## 4. 关键动作 — 实测配方

> 每条都是基于 §3 的参数 + 实测图(`calibration/D*.png`)确认,可以直接照搬到 panel.py。

### 4.1 举高过头(双手举到天上)

```python
# 关键:roll 拉到接近上限,pitch 保持 0,elbow 保持 0(让小臂直指天)
{
    "left_shoulder_roll_joint":  +2.8,   # 左臂几乎垂直指天
    "right_shoulder_roll_joint": -2.8,   # 右臂镜像
    "left_shoulder_pitch_joint":  0.0,   # 不前不后
    "right_shoulder_pitch_joint": 0.0,
    "left_elbow_joint":           0.0,   # 小臂与大臂重合
    "right_elbow_joint":          0.0,
    # 头部可以略抬
    "head_pitch_joint":          -0.2,
}
```
**实测视觉(D1 + B11 推断)**:大臂几乎垂直指天,小臂与大臂重合直指天。

### 4.2 鞠躬(弯腰 + 低头)

```python
{
    "waist_pitch_joint":  +0.5,  # 弯腰 90% 限位
    "head_pitch_joint":   +0.3,  # 低头
}
```
**实测视觉(D2 ✓)**:明显的弯腰低头。

### 4.3 推掌(单手前推,掌心朝前)

```python
{
    "right_shoulder_pitch_joint": -1.0,  # 大臂前推
    "right_shoulder_roll_joint":  -0.5,  # 微离身体
    "right_elbow_joint":           0.0,  # 小臂不弯,直推
}
```
**实测视觉(D5 ✓)**:右臂前伸,掌心朝前。

### 4.4 扭腰(左右摆胯近似 — 因为没 waist_roll)

```python
# 实际上是"左右扭上身",不是真正的"侧倾摆胯"
# 一个周期:0 → +0.3 → 0 → -0.3 → 0
{
    "waist_yaw_joint":  ±0.3,   # +0.3 向机器人左手扭, -0.3 向右
}
```
**实测视觉(D3 + B5/B6)**:整个上身左右小幅转动。

### 4.5 下蹲(替代"跳起" — 因为没 free joint)

```python
{
    "left_knee_joint":   +1.5,   # 浅蹲用 +0.6,深蹲用 +1.5(限位上限 1.9)
    "right_knee_joint":  +1.5,
    # 可选:髋微屈让蹲得更自然
    "left_hip_pitch_joint":   +0.3,
    "right_hip_pitch_joint":  +0.3,
    # 可选:头部前看
    "head_pitch_joint":   -0.1,
}
```
**实测视觉(B14)**:小腿后弯,身体下蹲。

### 4.6 挥手 / 摆动(原地)

```python
# 挥手:肩 roll 拉到侧平举 + 肘弯 + 肩 pitch 来回摆
{
    "right_shoulder_roll_joint":  -1.57,  # 侧平举
    "right_shoulder_pitch_joint":  0.0,    # pitch 周期 ±0.4 摆动
    "right_elbow_joint":          +0.8,   # 肘弯
}
```

### 4.7 T-pose / 自然站姿(双臂下垂)

```python
{
    "left_shoulder_roll_joint":   0.0,    # 默认就贴身体
    "right_shoulder_roll_joint":  0.0,
    "left_elbow_joint":          +1.0,    # 必须 +1.0 让小臂下垂(0 是前伸 90°)
    "right_elbow_joint":         +1.0,
    # 其它全部 0
}
```
**视觉**:大臂自然垂,小臂自然垂(标准 T-pose/自然站姿)。

### 4.8 双手合十(胸前,新发现 — 2026-08-09)

```python
{
    # 大臂前推
    "left_shoulder_pitch_joint":  -0.789, "right_shoulder_pitch_joint": -0.789,
    # 大臂贴身体(roll 接近下限,几乎为 0)
    "left_shoulder_roll_joint":   -0.006, "right_shoulder_roll_joint":  0.006,  # 镜像
    # 关键:肩 yaw 把大臂向中收(让双手在胸前并拢)
    "left_shoulder_yaw_joint":    -0.997, "right_shoulder_yaw_joint":  +0.997, # 镜像
    # 关键:elbow 负方向让小臂向上弯
    "left_elbow_joint":           -0.324, "right_elbow_joint":         -0.324,  # 同号
}
```
**实测视觉(3/4 + 正面)**:双手在胸前合拢,小臂垂直向上,大臂前推+内收。是真正的"双手合十"姿态。

### 4.9 累倒 / 倒地(因为没 free joint,不能"倒下" — 只能"躺倒"语义)

```python
# 真实"倒下"需要:腰后仰 + 头后仰 + 膝弯(模拟蹲下后仰)
{
    "waist_pitch_joint":         -0.5,  # 后仰到限位
    "head_pitch_joint":          -0.5,  # 仰头
    "left_knee_joint":           +0.5,  # 略蹲
    "right_knee_joint":          +0.5,
}
```
**注意**:实际不会真的倒地(脚仍在地上),只是身体后仰到极限。

## 5. 组合动作设计 checklist

做新动作时按这顺序检查:

1. **从 §4.7 的 T-pose 模板起步**(而不是 qpos0) — 否则小臂会前伸 90°
2. **改 pitch 类关节时**,先想"我要的是'前/上'还是'后/下'",再决定 +/- 号
3. **同时动双臂时**,左/右 roll 必是反号,左/右 pitch/是同号
4. **大动作别超限**:waist_pitch 限位只有 ±0.52(30°),小心鞠躬过头
5. **跑一次**:`.venv\Scripts\python.exe sim\calibrate.py --label <你的 label>` 单独看新动作的视觉
6. **新动作最好配新 PNG**:加到 calibrate.py 的 `TEST_POSES`,以后翻看
