# 007. 视频到机器人姿态 v2 分步验证

这套是从 0 重建的验证流水线,不依赖旧 `tools/pose_extract.py` / `tools/retarget.py`。

目标不是先追求效果最好,而是让每一步都能看见中间图像:

```text
视频 -> 抽帧 -> 2D/3D 人体姿态 -> 机器人关节角 -> 机器人渲染图 -> 人机对比图 -> Motion JSON
```

---

## 1. 代码入口

主入口:

```bash
.venv\Scripts\python.exe -m pose2robot.cli --help
```

核心模块:

| 文件 | 作用 |
|---|---|
| `pose2robot/video.py` | 视频信息、抽帧 |
| `pose2robot/pose_mediapipe.py` | MediaPipe 2D/3D 姿态识别 |
| `pose2robot/viz.py` | 人体 2D 叠图、3D 三视图 |
| `pose2robot/retarget.py` | 人体姿态到机器人 10 个上半身关节 |
| `pose2robot/retarget_ik.py` | 基于 MuJoCo FK 的上半身数值 IK 映射 |
| `pose2robot/render_robot.py` | MuJoCo 离屏渲染机器人姿态 |
| `pose2robot/reports.py` | CSV、报告、Motion 校验 |
| `pose2robot/gui.py` | 三栏图像验证 GUI |
| `pose2robot/cli.py` | 分步命令和端到端命令 |

## 3. 分步命令

### Step V0: 看视频基本信息

```bash
.venv\Scripts\python.exe -m pose2robot.cli video-info D:\Downloads\RGB视频数据集.mp4
```

验证点:

- 分辨率是否正确
- FPS 是否正常
- 帧数是否和视频时长匹配

### Step V1: 抽帧

```bash
.venv\Scripts\python.exe -m pose2robot.cli sample-frames D:\Downloads\RGB视频数据集.mp4 -n 8
```

输出:

```text
out/v2/RGB视频数据集/frames/
```

验证点:

- 人是否完整入镜
- 方向是否正确
- 采样帧是否覆盖完整动作

### Step A0: 识别人体 2D/3D 姿态

```bash
.venv\Scripts\python.exe -m pose2robot.cli detect-pose D:\Downloads\RGB视频数据集.mp4 --name RGB视频数据集
```

输出:

```text
out/v2/RGB视频数据集/pose.json
```

验证点:

- `frames` 等于视频实际帧数
- `pts` 有 2D 坐标和 visibility
- `world` 有 3D 坐标

### Step A0-check: 渲染人体姿态

```bash
.venv\Scripts\python.exe -m pose2robot.cli visualize-pose out\v2\RGB视频数据集\pose.json -n 12
```

输出:

```text
out/v2/RGB视频数据集/pose_viz/
```

验证点:

- `*_2d.png`: 骨架是否贴住人体
- `*_3d.png`: 3D 三视图是否连续、是否突然翻转

### Step A1/A2: 映射机器人并渲染

```bash
.venv\Scripts\python.exe -m pose2robot.cli map-robot out\v2\RGB视频数据集\pose.json --name RGB视频数据集_v2 --render --render-count 12 --export-panel
```

默认 `--method ik`,使用 MuJoCo FK 做数值 IK。也可以显式指定:

```bash
.venv\Scripts\python.exe -m pose2robot.cli map-robot out\v2\RGB视频数据集\pose.json --name RGB视频数据集_ik --method ik --render --render-count 12 --export-panel -o out\v2\RGB视频数据集\robot_ik
```

旧的直接公式只保留做对照:

```bash
.venv\Scripts\python.exe -m pose2robot.cli map-robot out\v2\RGB视频数据集\pose.json --method direct
```

输出:

```text
out/v2/RGB视频数据集/robot/joints.csv
out/v2/RGB视频数据集/robot/joints_report.md
out/v2/RGB视频数据集/robot/motion.json
out/v2/RGB视频数据集/robot/robot_viz/
sim/saved_motions/RGB视频数据集_v2.json
```

验证点:

- `joints_report.md` 里不要大量 `limit_hits`
- `robot_viz` 中机器人姿态应和人体动作语义一致
- Motion 应能被 `panel.py` 加载

### Step Compare: 生成左右对比图

```bash
.venv\Scripts\python.exe -m pose2robot.cli compare out\v2\RGB视频数据集\pose.json out\v2\RGB视频数据集\robot\motion.json -n 12
```

输出:

```text
out/v2/RGB视频数据集/compare/
```

验证点:

- 左侧人体骨架动作和右侧机器人动作时间对齐
- 如果不对,先判断是 2D/3D 识别错,还是 retarget 映射错

### Step Check: 校验 Motion

```bash
.venv\Scripts\python.exe -m pose2robot.cli check-motion out\v2\RGB视频数据集\robot\motion.json
```

验证点:

- 关节名都存在于 URDF
- 没有 NaN/Inf
- 没有超出 URDF 真实限位

## 5. 当前 v2 的边界

当前默认 IK 映射上半身 12 个关节:

- `head_yaw_joint`
- `head_pitch_joint`
- `waist_yaw_joint`
- `waist_pitch_joint`
- 左右肩 `pitch/roll`
- 左右肩 `yaw`
- 左右肘

暂不做:

- 腿部跟随
- wrist
- shoulder_yaw
- free joint / 行走位移

这是有意控制范围。先把“可看、可验证、可定位问题”的骨架搭稳,再逐个增加关节。

## 6. 下一步工程验证

优先级:

1. 看 `compare/*.png`,确认时间对齐和动作语义。
2. 看 `pose_viz/*_2d.png`,确认 MediaPipe 是否贴人。
3. 看 `pose_viz/*_3d.png`,确认 3D 是否翻转。
4. 看 `robot/joints_report.md`,找打满限位最多的关节。
5. 针对具体关节回到 `pose2robot/retarget.py` 调映射公式。

## 7. 实时三栏 GUI

启动:

```bash
.venv\Scripts\python.exe -m pose2robot.cli gui --source D:\Downloads\RGB视频数据集.mp4
```

界面分三块:

- 输入: 当前视频帧或摄像头帧
- 中间: 对当前帧实时计算出来的人体 2D 姿态叠图
- 输出: 当前帧映射后的 MuJoCo 机器人渲染图

下方展示:

- 输入源路径 / 摄像头编号
- 当前帧号、时间、FPS
- 单帧处理耗时
- MediaPipe 平均 visibility
- 当前机器人关节角

摄像头模式:

```bash
.venv\Scripts\python.exe -m pose2robot.cli gui --source 0
```

也可以在界面里点“打开视频”或“打开摄像头”切换输入源。

## 8. 机器人关节资料结论

本地官方目录:

```text
D:\Downloads\LingLong2.0_20260616\LingLong2.0_20260616
```

实际只有:

- `LingLong2.0.urdf`
- `LingLong_L1_V1.4.urdf`
- `meshes/`

没有找到官方动作重定向说明、SDK 示例或关节语义文档。因此关节映射不能按名字猜,必须以 URDF 为准。

URDF 里最关键的信息:

- `axis`: 关节正方向的旋转轴
- `origin xyz/rpy`: 子 link 相对父 link 的安装位姿
- `parent/child`: 真实运动链顺序
- `limit lower/upper`: 真实角度限位

当前应优先看关节 atlas:

```bash
.venv\Scripts\python.exe -m pose2robot.cli joint-atlas
```

输出:

```text
out/v2/joint_atlas/
out/v2/joint_atlas/_index.md
```

这批图用于人工确认每个关节正负方向,比读名字可靠。
