# 环境配置说明

本文档说明如何在 Windows 原生环境中配置本项目运行环境,用于视频/摄像头人体姿态识别、机器人姿态映射、MuJoCo 渲染和实时 GUI 验证。

---

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11 |
| Python | Python 3.9+ |
| 运行方式 | 建议使用项目独立虚拟环境 |
| 网络 | 首次安装 Python 包、下载模型时需要 |
| GPU | 非必需,当前链路 CPU 可运行 |

---

## 2. 创建虚拟环境

在项目根目录执行:

```bash
python -m venv .venv
```

激活环境:

```bash
.venv\Scripts\activate
```

确认 Python:

```bash
python --version
```

---

## 3. 安装依赖

项目依赖已写入:

```text
requirements.txt
```

安装命令:

```bash
pip install -r requirements.txt
```

如果使用国内网络环境,可以指定镜像源:

```bash
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

---

## 4. 依赖说明

| 依赖 | 用途 |
|---|---|
| `numpy` | 坐标系、向量、IK 数值计算 |
| `opencv-python` | 视频读取、摄像头读取、图像绘制 |
| `mediapipe` | 2D/3D 人体姿态识别 |
| `mujoco` | URDF 加载、机器人 FK、离屏渲染 |
| `PyQt5` | 实时三栏 GUI |
| `Pillow` | PNG 图像保存 |

---

## 5. 模型文件检查

项目需要两个模型资源:

| 模型 | 作用 |
|---|---|
| MediaPipe PoseLandmarker `.task` | 人体姿态识别 |
| LingLong2.0 URDF | 机器人模型、关节链、关节限位 |

确认 MediaPipe 模型存在:

```bash
Test-Path tools\models\pose_landmarker.task
```

确认机器人 URDF 存在:

```bash
Test-Path model\LingLong2.0\LingLong2.0.urdf
```

如果 MediaPipe 模型不存在,下载:

```bash
python -c "import urllib.request; urllib.request.urlretrieve('https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task', 'tools/models/pose_landmarker.task')"
```

## 6. 环境验证

在项目根目录执行:

```bash
python -m pose2robot.cli --help
```

能看到 `video-info`、`detect-pose`、`map-robot`、`gui` 等命令即表示基础环境可用。

检查视频读取:

```bash
python -m pose2robot.cli video-info D:\Downloads\RGB视频数据集.mp4
```

启动实时 GUI:

```bash
python -m pose2robot.cli gui --source D:\Downloads\RGB视频数据集.mp4
```

摄像头模式:

```bash
python -m pose2robot.cli gui --source 0
```

---

## 7. 离线完整流程

生成一段视频的完整验证产物:

```bash
python -m pose2robot.cli run-all D:\Downloads\RGB视频数据集.mp4 --name demo_motion --method ik
```

该命令会生成:

- 输入抽帧
- 人体姿态 JSON
- 人体 2D/3D 姿态图
- 机器人关节 CSV
- 映射质量报告
- Motion JSON
- 机器人渲染图
- 人机对比图

## 8. 常见问题

### 8.1 `ModuleNotFoundError`

说明依赖没有装到当前 Python 环境。先确认已激活 `.venv`,再执行:

```bash
pip install -r requirements.txt
```

### 8.2 GUI 启动后右侧黑屏

通常是 MuJoCo 模型加载或离屏渲染失败。先验证:

```bash
python -m pose2robot.cli joint-atlas
```

如果该命令也失败,优先检查 URDF 和 mesh 是否完整。

### 8.3 摄像头打不开

尝试切换摄像头编号:

```bash
python -m pose2robot.cli gui --source 1
```

### 8.4 MediaPipe 模型不存在

检查:

```bash
Test-Path tools\models\pose_landmarker.task
```

不存在时按第 5 节下载模型。

---

## 9. 推荐启动顺序

首次配置建议按以下顺序执行:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m pose2robot.cli --help
python -m pose2robot.cli joint-atlas
python -m pose2robot.cli gui --source D:\Downloads\RGB视频数据集.mp4
```

如果以上命令均能运行,说明开发环境、姿态识别、机器人模型加载和 GUI 渲染链路已配置完成。
